## 🌟 About the Academy

**Greater Light Global Consult & Online Academy (GLGC)** is a modern educational platform and business website founded and directed by **Engr. Ajibade Opeyemi Phillip**, a Civil Engineer, senior STEM educator, and international examination coordinator with over 15 years of classroom leadership.

The platform provides a dual-portal ecosystem:
1. **For Students:** Structured curricula across core STEM disciplines and standardized test prep, featuring an interactive virtual classroom with video playback, synchronized notes, formula sheets, checkpoint quizzes, and certificate verification.
2. **For Teachers:** A dedicated educator registration portal featuring an **80% Revenue Share Calculator**, a multi-step onboarding wizard, and a **Course Studio & Syllabus Builder** for publishing video lectures and learning materials.
3. **Study Abroad & International Admissions:** Integrated counseling for university admissions and scholarships in the **USA, UK, Canada, and Europe**.

## 🚀 Getting Started Locally

No complex dependencies required. Simply open `index.html` in any modern web browser, or run a local HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
